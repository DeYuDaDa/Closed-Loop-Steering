### 模块一：自动化前置状态监控器 (State Monitor)

本模块充当“脑电波探针”，包含两个来自最新论文的核心算法。

#### 1. EMA (Exponential Moving Average) - 捕捉瞬时与趋势 (取代原 TECA)

> [!IMPORTANT]
> **已弃用 (Outdated for Debug Only):** `TECA (Token Entropy Cumulative Average)`。由于累积平均具有“无限记忆”，导致在推理后期反应迟钝，现已全面替换为 EMA。

* **来源：** 优化自 *Explore Briefly, Then Decide*
* **数学表达：**
对于时间步 $t$，当前 Token 熵为 $H_t$。EMA 熵更新公式为：
$$\text{EMA}_t = \beta \cdot H_t + (1 - \beta) \cdot \text{EMA}_{t-1}$$
其中 $\beta = 0.1$（由 `config.EMA_BETA` 定义），赋予了监控器“遗忘机制”，能更快感知模型思路的回暖。


* **代码实现逻辑：**
* 在 `LogitsProcessor` 中，每生成一个 Token，接收一次 `scores` (即 logits)。
* 执行 `F.softmax` 和熵的计算。
* 维护一个全局变量 `entropy_sum` 和 `step_count`，实时计算并更新 `TECA`。



#### 2. ThinkBrake (Logit Margin) - 捕捉逻辑收敛

* **来源：** *ThinkBrake: Mitigating Overthinking in Tool Reasoning*
* **数学表达：**
定义当前预测的最优 Token 为 $y_t^\star = \arg\max(p_t)$，定义预设的终止/收敛 Token 为 $y_{\text{term}}$（在我们的实验中，通常是 `</think>` 的 Token ID）。
对数概率边际 (Margin) 为：

$$M_t = \log p(y_t^\star) - \log p(y_{\text{term}})$$


* **代码实现逻辑：**
* 获取 `scores` 后应用 `F.log_softmax` 得到 `log_probs`。
* 提取最大值 `max_log_prob = log_probs.max()`。
* 提取终止符的值 `term_log_prob = log_probs[term_token_id]`。
* 计算 $M_t = \text{max\_log\_prob} - \text{term\_log\_prob}$。
* **收敛锁存 (Latch Logic)：** 为防止模型在得出确定性结论后（例如已进入 `</think>` 判定区）继续受干预干扰，引入 Permanent Latch：
  一旦某一时刻 $M_t \le \tau_{\text{threshold}}$（$\tau=0.25$），则标记 `is_converged = True`，并在后续过程中永久保持锁定，强制干预强度 $\alpha = 0$。

### 模块二：基于主成分分析的流形投影 (Manifold Projection)

* **来源：** *Mitigating Overthinking in Large Reasoning Models via Manifold Steering*
* **数学表达：**
设通过 CAA 提取的原始向量为 $v_{\text{raw}} \in \mathbb{R}^d$。设模型正常推理时的隐状态激活矩阵为 $A \in \mathbb{R}^{N \times d}$。
1. 对中心化后的矩阵 $A$ 进行 PCA，提取前 $k$ 个主成分特征向量，构成正交基矩阵 $U_k = [u_1, u_2, \dots, u_k]$。
2. 将原始向量投影到这 $k$ 个主成分构成的低维流形上：

$$v_{\text{manifold}} = \sum_{i=1}^k (v_{\text{raw}} \cdot u_i) u_i$$




* **代码实现逻辑 (离线阶段)：**
* 使用 `sklearn.decomposition.PCA` 拟合收集到的 Hidden States。
* 提取 `pca.components_[:k]`。
* 使用点积计算投影分量并累加，生成新的 `v_purified.pt` 供注入器使用。

### 模块三：基于 PID 的动态强度控制器 (Dynamic Controller)

* 模块三：基于 PD 的动态强度控制器 (Dynamic Controller)

  * **理论依据：** 改进自离散 PID 控制理论，为防止累积误差导致“积分饱和 (Integral Windup)”，剔除积分项，采用高敏捷的 PD (比例-微分) 架构。
  * **数学表达：**
  设设定的安全熵阈值为 $\text{SetPoint}$（例如 0.15），当前步的 $\text{EMA}_t$ 为过程变量。
  1. 误差：$e_t = \text{EMA}_t - \text{SetPoint}$
  2. 比例项 (P)：$P_t = K_p \cdot e_t$ （$K_p$ 取较大值，如 8.0，以放大微小高维误差）
  3. 微分项 (D)：$D_t = K_d \cdot (e_t - e_{t-1})$
  4. 目标插值强度：$\alpha_t = P_t + D_t$
  5. 硬截断防护 (ThinkBrake 刹车机制)：如果探针传入的 `is_converged` 为真（对数边际收敛），则无视熵的残余惯性，强制阻断干预 $\alpha_t = 0$。
  6. 物理边界裁剪：$\alpha_t = \text{Clamp}(\alpha_t, 0, \alpha_{\max})$ （其中 $\alpha_{\max} \in (0, 1)$ 代表允许的最大闭合百分比）

* **代码实现逻辑：**
* 编写一个 `PIDController` 类，维护 `prev_error` 和 `integral`。
* 每次 `LogitsProcessor` 算出新的 EMA 后，调用 `pid.step(EMA)` 获取最新的 $\alpha_t$。
* 将 $\alpha_t$ 传递给底层的 Hook。

* ### 模块四：保范数球面干预引擎 (Spherical Steering)

  这是本次重构的最核心、数学要求最严格的部分。为了避免传统加法干预带来的状态休克，采用基于球面线性插值（SLERP）的保范数旋转机制。

  * **来源：** *Spherical Steering: Geometry-Aware Activation Rotation for Language Models*
  * **数学表达：**
  设当前隐状态为 $h \in \mathbb{R}^d$，目标纯化控制向量为 $v \in \mathbb{R}^d$（已归一化，$||v||_2 = 1$），插值强度为 $t = \alpha \in [0, 1]$（由 PD 控制器提供，代表向目标向量靠拢的百分比）。
  1. 提取 $h$ 的单位方向向量及原始模长：
     $$\hat{h} = \frac{h}{||h||_2}$$
  2. 计算当前隐状态与目标向量的真实几何夹角 $\theta$：
     $$\theta = \arccos(\hat{h} \cdot v)$$
  3. 根据插值强度 $t$ 缩短夹角（例如 $t=0.3$，则当前夹角缩小 30%）：
     $$\theta_{\text{new}} = (1 - t) \cdot \theta$$
  4. 在 $h$-$v$ 构成的二维超平面内，构建垂直于目标向量 $v$ 的正交单位基 $u$：
     $$u = \frac{\hat{h} - \cos(\theta)v}{\sin(\theta)}$$
  5. 执行 SLERP 球面插值旋转：
     $$\hat{h}_{\text{rotated}} = \cos(\theta_{\text{new}})v + \sin(\theta_{\text{new}})u$$
  6. 恢复隐状态的初始模长（严格保范数）：
     $$h_{\text{new}} = ||h||_2 \cdot \hat{h}_{\text{rotated}}$$

  * **代码实现逻辑 (在 Forward Hook 中)：**
  * 引入 `clamp_min(1e-6)` 防御高维空间除零导致的 NaN 梯度爆炸。
  * 引入 `clamp(-1.0 + eps, 1.0 - eps)` 防御点积浮点误差导致的 `arccos` 越界。
  * 计算正交基与旋转矩阵，最后将新向量乘以原始 `h_norm` 写回大模型的残差流。

### 补充模块五：多维评估矩阵中的 DTR 计算核心 (`dtr_evaluator.py`)

我们需要明确 DTR 在新架构中的角色定位：**DTR 从“触发器”退居为“终极评估金标准”**。
虽然 DTR 不参与实时干预打方向盘，但它必须作为**事后裁判**，以证明我们的球面干预确实激发了深层计算。

为了确保代码完整，补充 DTR 的数学实现逻辑如下：

* **理论依据：** *Think Deep, Not Just Long: Measuring LLM Reasoning Effort via Deep-Thinking Tokens* (Algorithm 1)
* **数学表达：**
给定一条生成的轨迹（包含 $N$ 个 Token），对于每个 Token $t$：
1. 获取其在所有层 $l \in \{1..L\}$ 的隐状态 $h_{t,l}$。
2. 解嵌入投影：$p_{t,l} = \text{Softmax}(W_U h_{t,l})$
3. 计算层级散度：$D_{t,l} = \text{JSD}(p_{t,L} || p_{t,l})$
4. 寻找收敛深度（严格单调递减判定）：

$$c_t = \min \{ l \mid \min_{j \le l} D_{t,j} \le g \}$$



（其中 $g=0.5$ 为收敛阈值）
5. 深度思考判定：如果 $c_t \ge \lceil \rho L \rceil$（通常 $\rho=0.85$），则该 Token 记为 $1$，否则为 $0$。
6. **干预区间 Local DTR：** $$\text{Local\_DTR} = \frac{\sum_{t \in \text{Intervention\_Window}} \mathbb{I}(c_t \ge \rho L)}{\text{Length}(\text{Intervention\_Window})}$$

* **关键改进：** 在新的实验中，我们要统计的不再是滞后的 `<critic>` 标签内的 DTR，而是 **“EMA 动态触发干预窗口内”** 的 DTR。
* 我们将对比：**触发前的 DTR $\rightarrow$ 触发后的 DTR（必须激增） $\rightarrow$ 伴随的 EMA 变化（断崖式降熵）**。




* **代码实现逻辑 (离线分析阶段)：**
* 复用并优化我们之前写的 `dtr_utils.py`。
* **关键改进：** 在新的实验中，我们要统计的不再是 `<critic>` 标签内的 DTR，而是**“TECA 触发干预窗口内”**的 DTR。
* 我们将对比：**触发前的 DTR（通常处于中等） $\rightarrow$ 触发后的 DTR（必须激增） $\rightarrow$ 伴随的 TECA 变化（必须骤降）**。
